# Peetty Flutter example

A demo screen with cards and buttons marked as perches, a figure picker, activity levels and buttons that ask the companion to act.

```bash
flutter pub get
flutter run -d chrome   # or macos, ios, android
```

To run on a physical iOS device, open `ios/Runner.xcworkspace` in Xcode, choose your own team under **Signing & Capabilities**, and change the bundle identifier (`dev.idy.peettyExample`) to one your team can sign. The project does not pin a development team.
